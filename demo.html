Project Vision

TACTIX // BLACKBOX is a strategic tic-tac-toe engine (3×3, 4×4, 5×5) based on game trees and Minimax. We wanted something more than a basic game: an operator vs system simulation with a “cyber” atmosphere. The goal was to mix clean logic + immersive UI, and keep the code modular and testable.

MINIMAX MODULAR GAME ENGINE

Core Modules

The project is split into clear parts: game logic, AI decisions, and persistent stats. The UI only coordinates actions, while the backend engine guarantees legality and consistency. This separation helped us debug faster and keep the system stable.
